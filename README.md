# AlgoViz - Data Structures & Algorithms Visualizer

Interactive web-based visualizations for learning data structures and algorithms.

## Features

**Data Structures:**

- Stack
- Queue
- Linked List
- Binary Search Tree (BST)
- AVL Trees

**Sorting Algorithms:**

- Bubble Sort
- Insertion Sort
- Selection Sort
- Merge Sort
- Quick Sort

**Searching Algorithms:**

- Linear Search
- Binary Search

## Technologies

- HTML5
- CSS3
- JavaScript

## Usage

Open `index.html` in your web browser to explore interactive visualizations of various data structures and algorithms.

## Project Structure

```
├── index.html          # Main landing page
```
