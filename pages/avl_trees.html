AVL TREE VISUALIZATION

"Self-Balancing Binary Search Tree"

How AVL Tree Works

➕ Insert Operation

Adds a new node following BST rules, then performs rotations if needed to maintain balance.

➖ Delete Operation

Removes a node and rebalances the tree using rotations to maintain AVL properties.

🔄 Rotations

Left, Right, Left-Right, and Right-Left rotations maintain tree balance (height difference ≤ 1).

⚖️ Balance Factor

Height difference between left and right subtrees. Must be -1, 0, or 1 for all nodes.
