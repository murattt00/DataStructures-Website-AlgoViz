"Ordered Binary Tree Structure"

How Binary Search Tree Works

➕ Insert Operation

Adds a new node following BST rules: left child < parent < right child.

➖ Delete Operation

Removes a node while maintaining BST properties. Handles three cases: leaf, one child, two children.

🔍 Search Operation

Efficiently finds a value by comparing and traversing left or right based on the value.

📏 BST Property

For every node: all left descendants < node < all right descendants.
