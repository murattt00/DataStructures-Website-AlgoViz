STACK VISUALIZATION

"LIFO - Last In, First Out"

How Stack Works

🔼 Push Operation

Adds a new element to the top of the stack. The new element becomes the top.

🔽 Pop Operation

Removes and returns the top element from the stack. The element below becomes the new top.

👁️ Peek Operation

Returns the top element without removing it. Useful for viewing the top element.

📏 LIFO Principle

Last In, First Out - The most recently added element is removed first.
