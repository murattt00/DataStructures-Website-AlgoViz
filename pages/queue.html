QUEUE VISUALIZATION

"FIFO - First In, First Out"

How Queue Works

➕ Enqueue Operation

Adds a new element to the rear (back) of the queue. New elements join at the end.

➖ Dequeue Operation

Removes and returns the front element from the queue. The next element becomes the new front.

👁️ Peek Operation

Returns the front element without removing it. Useful for viewing the next element to be served.

📏 FIFO Principle

First In, First Out - The oldest element (first added) is removed first, like a real queue.
