"Find the minimum, place it at the start."

How Selection Sort Works

🔍 Find Minimum

Repeatedly finds the minimum element from the unsorted portion of the array.

🔄 Place at Start

Swaps the minimum element with the first unsorted position in each pass.

⏱️ Time Complexity

Always O(n²) for best, average, and worst cases - not adaptive to input.

❌ Not Stable

May change relative order of equal elements. Simple but inefficient for large datasets.
