How Linear Search Works

🔍 Sequential Check

Checks each element in the array one by one from start to end until the target is found.

📊 Unsorted Arrays

Works on both sorted and unsorted arrays. No preprocessing required.

⏱️ Time Complexity

Best: O(1) when element is first. Worst: O(n) when element is last or not present.

✅ Simple & Reliable

Straightforward implementation. Guaranteed to find element if it exists.
