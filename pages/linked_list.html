How Linked Lists Work

🔗 Singly Linked List

Each node has a value and pointer to the next node. Traversal is one-way only.

⇄ Doubly Linked List

Each node has pointers to both next and previous nodes. Allows bidirectional traversal.

🔄 Circular Linked List

Last node points back to the first node, creating a circular structure.

➕ Operations

Insert at head/tail, delete by value/position, search for values in the list.
