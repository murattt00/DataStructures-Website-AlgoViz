How Binary Search Works

✂️ Divide & Conquer

Repeatedly divides the sorted array in half, eliminating half of remaining elements each step.

📊 Sorted Arrays Only

Requires a sorted array. Compares target with middle element to decide which half to search.

⏱️ Time Complexity

O(log n) - Much faster than linear search for large arrays. Logarithmic time complexity.

⚡ Highly Efficient

Can search through millions of elements in just a few comparisons.
